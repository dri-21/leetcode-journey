# Running Sum of 1d Array — LeetCode 1480

## Approach
- Initialise `sum = 0`.
- Traverse the array once, adding each element to `sum`.
- Store each running sum in the output array.
- Return the output array.

## Complexity
- Time: O(n)
- Auxiliary space: O(1), excluding output.
- Output space: O(n).
